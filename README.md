# Mike Salemi App (v2)

Web app for Mike Salemi's programs, retreats and coaching. Built so the iPhone and Android apps can be added later on the same backend and engine.

- `apps/web` Next.js 16 (Vercel, San Francisco)
- `packages/core` training engine (KBL rules, readiness, schedules, pricing)
- `packages/api` typed Supabase data layer
- `packages/tokens` design tokens
- `supabase/migrations` database v2

Plan: see the Rebuild Plan doc. Specs per workstream: `docs/specs/`.
