# LIVE Kettlebell Journey

i want to make an app. that features a program called Kettlebell Lifestyle. 

This has 3 ways for people to go through the program. 

Immersion - tracks progress, encoruages to move foward. linear progression. 

Self guided - shows all phases - levels - days at one place. user can go anywhere on a specific phase, level or day. 

Library - all videos available with filters i.e workouts, on ramp etc. 

then there are tools. kettlebell selector, stretch test. these tools mainly ask questions, and that way, then give out the results. 

then immersion and self guided has days under phases. and each day has sub-lessons and associated videos for each day. 

all the videos on this will be hosted on vimeo.
