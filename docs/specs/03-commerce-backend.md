## Rules (from the plan)
- Access comes from plans (Free/Pro/Max, monthly/yearly) and one-time purchases. Per plan × program benefit: none / discount % / included (table `plan_program_benefits`). Inclusion lasts while the plan is active; purchases keep their terms; best eligible price; discounts never stack (coupon vs plan discount: take the larger, unless the coupon says stackable — not supported now); a higher plan is never worse; progress never deleted.
- Retreat places and coaching credits are bought directly (never via in-app purchase later).
- Only server code writes `orders`, `order_items`, `subscriptions`, `access_grants`, `coaching_credits`, `points_ledger`, `member_badges`, `referrals`. Prices are computed on the server; the browser sends only what it wants to buy.
